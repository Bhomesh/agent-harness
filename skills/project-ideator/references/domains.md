# Project Ideator Domain Matrix & Catalogs

### 1. AI, RAG & Autonomous Agent Systems
- **Idea Archetypes**: Multi-agent code review swarms, deterministic workflow orchestrators, offline private LLM hubs with local RAG (Ollama / Llama.cpp), self-healing synthetic test generators, multimodal documentation indexing.
- **Recommended Tech**: Python / FastAPI / TypeScript, LangGraph, Qdrant / pgvector / Chroma, LiteLLM, Ollama, Docker.

### 2. Full-Stack & Modern SaaS
- **Idea Archetypes**: Real-time collaborative canvas / document tools (CRDTs), automated customer retention engine, vertical ERP for indie makers, webhook observability proxy, API mock & traffic replay engine.
- **Recommended Tech**: Next.js 15 / React 19, Tailwind CSS, PostgreSQL, Redis, BullMQ / Celery, Prisma / Drizzle ORM.

### 3. Developer Ergonomics & DevOps
- **Idea Archetypes**: Ephemeral preview environment orchestrator, secret rotation canary, Git commit semantic lint and change impact analyzer, distributed trace visualizer for local microservices.
- **Recommended Tech**: Go / Rust / Python, Docker API, SQLite / DuckDB, BubbleTea / Click / Typer CLI, OpenTelemetry.

### 4. Mobile & Edge Computing
- **Idea Archetypes**: Local-first encrypted personal vault with peer-to-peer sync, audio transcription and action-item extractor running on-device, sensor-based habit & posture tracker.
- **Recommended Tech**: React Native / Expo, Flutter, WatermelonDB / SQLite, WebSockets.

### 5. FinTech & Web3
- **Idea Archetypes**: Automated portfolio rebalancing bot, multi-chain gas fee optimizer & smart scheduler, invoice factoring & automated reconciliation engine, expense split & settlement platform.
- **Recommended Tech**: TypeScript / Go, Viem / Ethers, PostgreSQL, TimescaleDB, Stripe API / Plaid API.
